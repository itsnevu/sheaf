# Self-hosted interface fonts

These Latin WOFF2 files are the same Google Fonts assets previously emitted by the successful Next.js production build for Barlow, Barlow Condensed, Playfair Display and JetBrains Mono. They are bundled so production and Docker builds no longer depend on Google Fonts responses or URL formats.

The original SIL Open Font License and copyright notices for each family are included alongside the fonts in the corresponding `*-OFL.txt` files. Sources: the `ofl/barlow`, `ofl/barlowcondensed`, `ofl/playfairdisplay` and `ofl/jetbrainsmono` directories of https://github.com/google/fonts.
