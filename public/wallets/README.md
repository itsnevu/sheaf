Wallet brand assets vendored from `@web3icons/core` 4.0.58 (MIT),
https://web3icons.io / https://github.com/0xa3k5/web3icons.

MetaMask and Rabby use the branded variant. Phantom and Solflare use the
background variant. Logos remain the property of their respective owners.

These files are served locally so wallet selection does not depend on
third-party favicon endpoints or GitHub URLs.
