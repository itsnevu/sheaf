# Raqio project guidance

Before creating or editing any Raqio visual, read [RAQIO_VISUAL_GUIDE.md](RAQIO_VISUAL_GUIDE.md) and view its primary reference image. Follow that guide for topic-specific illustration, right-side blue opacity overlay, white typography/logo, and delivery to Downloads. This applies to social posts, article illustrations, covers, infographics, and video artwork; it does not require changes to unrelated application code.

Keep visual instructions in that single guide. When the user changes the visual direction, update the guide rather than duplicating its rules elsewhere.
